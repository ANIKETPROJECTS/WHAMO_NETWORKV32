# Additional Features of WHAMO Network Designer

WHAMO Network Designer adds visual modeling, file-management, and result-review tools around the WHAMO workflow. WHAMO remains the hydraulic simulation engine; the features below describe additions provided by the application.

## Features

1. **Graphical user interface:** Build and edit a hydraulic network on a visual canvas instead of preparing every network detail as text.

2. **2D network mapping:** View network elements and their connections together, arrange the layout, and inspect the system diagram.

3. **3D network view:** Open a three-dimensional view to inspect the network layout from different angles.

4. **Shape and geometry options:** Select supported conduit shapes. For non-circular conduit shapes, the application displays an equivalent diameter for the generated WHAMO input. Surge tanks also support SHAPE elevation-and-area data.

5. **Wave-speed assistance:** Select a pipe material to fill supported material properties, then calculate wave speed when the required geometry and wall-property values are available. Manual values can be entered where the interface allows them.

6. **SI and FPS units:** Choose SI or FPS units while editing the network. The visualization section also provides unit controls for graphs and their corresponding data.

7. **Simulation parameter setup:** Configure time stages and other available computational settings in the application before generating an input file.

8. **Output-request configuration:** Select HISTORY output requests manually, so only the requested variables are included in the generated input.

9. **WHAMO file workflow:** Import and generate `.INP` files, and load `.OUT` results for review. The generated input can be edited or run with the WHAMO executable as required.

10. **Results visualization:** Review profile and history graphs, simulation summaries, and raw result data in the application.

11. **Flex Table:** Review and edit supported network properties in a table, including filtering the displayed data.

12. **Excel import and export:** Exchange supported network data with Excel workbooks, including workbook sheets available through the Flex Table tools.

13. **Project saving and opening:** Save projects, reopen them later, or save a separate project file.

14. **User and permission management:** Administrators can manage user accounts and control access to application sections.

15. **Cloud-supported, multi-device access:** The hosted web application can be accessed from Windows computers, tablets, and other supported devices through a compatible browser and internet connection. Access to projects and other server-based features depends on the configured deployment and user permissions.

## Summary

The application makes WHAMO model preparation and result review more visual and organized. It does not replace the WHAMO simulation engine; it provides tools for building networks, preparing input, managing projects, and reviewing results.
